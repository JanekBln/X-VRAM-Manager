X-VRAM Manager - Changelog
===========================

v0.4.1
------
- Replaced the O/0-style active indicator with a real colored LED glyph.
- Green LED = X-VRAM pager tuning active; red LED = inactive/off.
- Removed window resizing; monitor is now fixed-size but remains movable.
- Added APPLY, RELOAD and RESTORE buttons directly to the monitor.
- Added the same Apply / Reload Config / Restore Stock actions to the Plugins menu.
- Core VRAM/pager tuning logic remains unchanged.

v0.4.0
------
- Added an optional semi-transparent in-sim VRAM monitor.
- Monitor opens from Plugins -> X-VRAM Manager -> VRAM Monitor.
- Movable title strip, resizable edges and small X close control.
- Displays process VRAM usage, DXGI budget, headroom and dedicated GPU VRAM.
- Green lamp indicates active X-VRAM pager tuning.
- Monitor stays hidden by default and polls telemetry only while visible.
- Tested pager-control logic from v0.3/v0.3.1 remains unchanged.

v0.3.1
------
- Fixed XPPython3 4.7.1 compatibility.
- Added the required PythonInterface class for PI_*.py plugins.
- Switched to the documented import: from XPPython3 import xp.
- VRAM / texture-pager tuning logic unchanged from v0.3.

v0.3
----
- Standalone XPPython3 texture-pager tuning plugin.
- No MotionVectors/TAA Vulkan layer required.
- Late resolution of X-Plane private pager controls.
- Safe restoration of original pager values on Python reload or disable.
- Conservative default tuning:
  max_overdrive = 64
  size_fudge_factor = 0.75
- scale_floor disabled by default.
- Optional binary reserve patch remains signature-guarded and fails safely.
- Tested through multiple Python reloads, real-weather activation and a
  complete flight through landing.
