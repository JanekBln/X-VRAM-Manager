# X-VRAM Manager v0.4.3

- Added a 32 / 64 texture-level switch to the in-sim VRAM Monitor.
- 32 = Balanced mode with more VRAM headroom.
- 64 = Aggressive mode for maximum texture quality.
- Added a mouse-over tooltip explaining both levels.
- Selected level is saved to `XVRAM_Manager.ini`.
- PAGER and FUDGE display live X-Plane values.
- RESTORE holds captured stock values until APPLY or RELOAD.
